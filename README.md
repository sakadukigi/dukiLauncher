# dukiLauncher

dukiLab. のデザインシステムを取り入れた Android のホームアプリ（ランチャー）です。

モノクロ、角丸なし、左上の45°三角マーク、方眼の背景で組んでいます。色・書体・寸法は、デザインシステム（Artifact「dukiLab.」）のトークンをそのまま移しています。

## できること

- ホーム画面：黒いヘッダー（ロゴ・秒まで出る時計・日付）、方眼のページにアプリとフォルダ、下にドック（最大5個）
- 並べ替え：アイコンを長押ししてそのまま動かす。アプリをアプリに重ねるとフォルダ、ドックに落とすとドックへ。画面の端で止めると隣のページへ
- フォルダ：名前をその場で変えられる。中のアプリは長押しして動かすと並べ替え、カードの外で離すとフォルダから出す。長押しメニューから「フォルダから出す」「フォルダを解く」
- 同じアプリをホーム画面に何個でも置ける（アプリ一覧の「ホーム画面に置く」、ホーム画面の「ホーム画面にもう1つ置く」）
- Web ページ：Chrome などの「ホーム画面に追加」を受け取ってショートカットとして置く。URL を入れて置くこともできる（何もないところを長押し →「Webページを追加」、または設定から）
- アプリ一覧：上にスワイプで開く。見出し（A〜Z・あ〜わ・#）ごとに並ぶ。検索はひらがな・カタカナ・全角半角・大文字小文字を区別しない
- 長押しメニュー：ホーム画面に置く／外す、ドックに追加／外す、ドック内の並べ替え、アプリ一覧で非表示、アプリ情報、アンインストール
- 操作：下スワイプで通知パネル（検索・なしにも変更可）、ダブルタップで画面オフ（ユーザー補助を有効にしたとき）
- アイコン：既定はモノクロ。Android 13 以降のテーマアイコンがあれば ink 色で塗り、なければ白黒にする
- 設定：テーマ（端末に合わせる・ライト・ダーク）、アイコンの色、列数・段数、アプリ名の表示、時計の秒、新しいアプリを自動で置く、非表示のアプリ、既定のホームアプリの選択、デザイン部品の一覧
- 仕事用プロフィールのアプリにも対応

対応する Android は 12（API 31）以上です。

## 構成

| モジュール | 中身 |
| --- | --- |
| `:core` | 検索・索引・ホーム画面の配置（フォルダ・ページ）・ドック・保存形式・時計表記（Android 非依存、JVM で単体テスト） |
| `:app` | 画面（Jetpack Compose）、アプリ一覧の読み込み、アイコン、設定の保存、Android とのつなぎ |

- `app/src/main/java/com/dukilab/launcher/ui/theme/`：デザイントークン（色・文字・寸法）
- `app/src/main/java/com/dukilab/launcher/ui/components/`：カード・ボタン・タグ・ヘッダー・入力欄・方眼・三角マークなどの部品

## ビルドとテスト

GitHub Actions が、プッシュとプルリクエストのたびにテストと APK のビルドを行い、APK を成果物（`dukiLauncher-debug-apk`）として保存します。

手元では Android Studio（JDK 17 以上）で開くか、コマンドで実行します。

```
./gradlew :core:test                # ロジックの単体テスト
./gradlew :app:testDebugUnitTest    # 画面のテスト（Robolectric）
./gradlew :app:assembleDebug        # APK を作る（app/build/outputs/apk/debug/）
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

デバッグ版は `app/debug.keystore` で署名するので、どこでビルドしても上書きインストールできます。
